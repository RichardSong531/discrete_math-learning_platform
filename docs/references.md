## Recording reviewed sources

Record title, author/institution, edition/date, stable URL, access date, relevant
pages/sections and node IDs, and reuse terms. Distinguish curriculum inspiration,
factual verification, quotations, and adaptations. Record what was checked and any
uncertainty. Include external PDFs only when redistribution is permitted; repository
