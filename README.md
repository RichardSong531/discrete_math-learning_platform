# Discrete Quest

**Master Discrete Math, One Quest at a Time.**

Discrete Quest is an evolving interactive learning project for
Discrete Mathematics.

The project began with a simple problem: there are already many
good Discrete Mathematics resources online, but as a learner it
can still be difficult to know what to learn first, what concepts
depend on each other, how much practice is enough, and when a topic
is truly mastered.

Instead of building another digital textbook, Discrete Quest
organizes the subject as a visual mastery roadmap.

Each topic is broken into knowledge nodes connected by prerequisites.
A learner can explore a concept visually, interact with examples,
practice it, complete a mastery check, and see what to learn next.

## Current Stage

The project is currently being built as a collection of standalone
interactive learning maps.

Initial modules include:

- Logic
- Set Theory
- Relations

Each module experiments with:

- knowledge dependency graphs
- visual and intuitive explanations
- worked examples
- interactive practice
- common mistake explanations
- mastery checks
- mixed review
- recommended next concepts

These modules are prototypes for the larger learning system rather
than the final website architecture.
