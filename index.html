A simple way to learn

  1. Pick a knowledge node

    Open a map and choose a node. The connecting lines show prerequisites. Read the intuition and worked example, then try the interactive lab.

  2. Check your understanding

    Answer the Mastery Check and read the feedback. Revisit mistakes before trying again. The score is a practice signal, not a final assessment.

  3. Review, then keep going

    Use Cheat Sheet for a quick reminder and Mixed Practice for review. Recommended next helps within the map; the topic navigation takes you to another map.

About progress, offline use, and these learning maps

Your progress is saved locally when browser storage is available. Use the same browser and address to return to it. Clearing site data removes saved progress; there is no account or cross-device sync. Moving from a downloaded file to a local server does not automatically move progress.

After downloading the project, open this index.html to browse the topics. For more consistent storage behavior, serve the project locally using the README instructions. These are evolving learning prototypes; some topics and written-proof practice are still being developed.
