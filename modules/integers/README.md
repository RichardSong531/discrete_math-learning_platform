# Integers

Standalone interactive learning map with 34 knowledge nodes, 136 practice questions,
and 48 glossary entries. Open [index.html](index.html), or use the local server in the
[root README](../../README.md#run-locally). The topic navigation connects all six maps.

Start with basic integer arithmetic, Logic, and Sets. Coverage includes division with
remainder, divisibility, parity, number bases, primes and factorization, gcd and lcm,
Euclid's algorithm, Bézout coefficients, modular inverses, factorials, and floor/ceiling.
Permutations is the preceding topic in the suggested browsing route, not a prerequisite
for every Integers lesson.

Progress is saved in this browser's localStorage when available. Each node has four
questions; mastery requires 4/4. Mixed Practice reviews opened nodes (or all nodes if
none are opened) without changing node mastery. Submitted sets are locked; use Reset
check or New mixed set to retry. There is no account or synchronization.

## Import and review

Imported from `Integers_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Steven T. Dougherty, André Leroy, and Esengül Saltürk, *Properties Of Integers*.
The repository version corrects two arithmetic examples, clarifies signed/zero cases,
removes a prerequisite cycle, and validates calculator input. Large base conversions
and Mersenne perfect numbers use exact integer arithmetic. Questions shuffle their
answer choices while preserving the answer key.

The original download is unchanged. See [source notes](references.md) and
[coverage and validation](coverage.md) for the scope of the review.
