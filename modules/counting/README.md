# Counting

Standalone interactive learning map with 31 knowledge nodes, 124 practice questions,
and 46 glossary entries. Open [index.html](index.html), or use the local server in the
[root README](../../README.md#run-locally). Topic navigation connects all eight maps.

Start with basic arithmetic, Logic, and Sets. Functions and Permutations provide useful
connections. The guide places Counting after Matrices for browsing; Matrices is not a
prerequisite. Topics include the product rule, powersets, permutations and combinations,
repeated objects, Pascal's triangle, the binomial theorem, pigeonhole arguments, and
constrained counting with chess positions, card hands, passwords, and ranked awards.

Progress is saved in this browser's localStorage when available. Each node has four
questions with shuffled order and answer choices; mastery requires 4/4. Mixed Practice
reviews opened nodes (or all nodes when none are opened) without changing node mastery.
Use Reset check or a new mixed set to retry. There is no account or synchronization.

## Import and review

Imported from `Counting_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Steven T. Dougherty, Gary Greaves, and Frédérique Oggier, *Combinatorics* (January 10,
2026). All nodes, question keys/explanations, and glossary terms were reviewed.
The repository version clarifies an ambiguous frequency question and formula domains,
validates lab inputs, and improves grading, saved-progress recovery, and keyboard use.
Counting calculations use exact integer arithmetic within the displayed input limits.

The original download is unchanged. See [source notes](references.md) and
[coverage and validation](coverage.md) for details and remaining depth.
