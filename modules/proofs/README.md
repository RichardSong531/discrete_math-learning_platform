# Methods of Proof

Standalone Methods of Proof learning map with 40 knowledge nodes, 160 practice
questions, and 51 bilingual glossary entries. Open [index.html](index.html), or
follow the server instructions in the [root README](../../README.md#run-locally).
The shared [topic guide](../../index.html) connects all available maps in a suggested sequence.

Start with Logic and Integers: implications, quantifiers, parity, and divisibility
are used throughout. Sets supplies useful background for domains and induction.
Completing every preceding map is not a prerequisite.

The chapter covers proof foundations, direct proof, definitions, case analysis,
universal and existential claims, uniqueness, contraposition, biconditionals,
contradiction, and ordinary induction. It includes induction from a starting index
other than 1; **strong induction is still a remaining curriculum task**.

Labs let learners inspect counterexamples, truth values, finite quantifiers, parity,
divisibility witnesses, proof-step order, common errors, and induction steps.
A per-node proof notebook stores written drafts separately from quiz progress.
Drafts are not automatically graded or certified as valid proofs. Static rule and
biconditional diagrams provide reference material alongside the interactive labs.

Each node has a four-question check. A complete 4/4 check marks mastery; 3/4 marks
partial progress. Questions and choices are shuffled, and a new question order
starts a fresh attempt. Mixed Practice draws up to 12 questions from explored nodes,
or from all nodes if none have been explored, without updating individual mastery.
Progress and proof drafts stay in this browser when storage is available; there is
no account or synchronization.

## Import and review

Imported from `MethodsOfProof_Interactive_Knowledge_Map_Enhanced.html` and reviewed
against Michael P. Allocca's supplied 23-page *Methods of Proof* chapter. All 40
nodes, 160 question keys and explanations, 51 glossary entries, and proof-scaffold
text were reviewed. The original downloads remain unchanged.

The repository version retains the supplied map's corrections to source typos and
clarifies divisibility notation, quantifier scope, and proof-method limits. See
[source notes](references.md) and [coverage and validation](coverage.md).
