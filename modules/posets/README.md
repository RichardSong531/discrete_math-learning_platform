# Posets

Standalone Partially Ordered Sets learning map with 41 knowledge nodes, 164 practice
questions, and 48 bilingual glossary entries. Open [index.html](index.html), or follow
the server instructions in the [root README](../../README.md#run-locally). The shared
topic guide connects all ten maps and provides a suggested learning sequence.

Start with Sets and Relations. Integers supplies divisibility, prime factorization,
and gcd/lcm; Functions helps with isomorphisms; Logic supports Boolean operations
and proof vocabulary. Graphs is useful for reading diagrams, but finishing every
preceding topic is not a prerequisite.

The chapter proceeds from posets, comparability, Hasse diagrams, extrema, bounds,
and isomorphisms to lattices, meet/join, lattice laws, complements, modularity,
Boolean algebras, bitstrings, and truth-table construction. Interactive labs include
an editable four-element relation, divisor lattices, a three-element power set,
a bowtie counterexample, fixed isomorphism pairs, four lattice models, bit operations,
and a three-variable truth-table editor.

Each node has a four-question check. A complete 4/4 check marks mastery; 3/4 marks
partial progress. Questions and choices are shuffled, and New set permits a
fresh attempt. Mixed Practice draws up to 12 questions from explored nodes, or from
all nodes if none have been explored, without updating individual mastery. Progress
stays in this browser's localStorage when available; there is no account or sync.

## Import and review

Imported from `Poset_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Steven T. Dougherty, Michael Engling, and Serap Şahinkaya, *Partially Ordered Sets*,
the supplied 34-page chapter. All 41 nodes, 164 answer keys and explanations, and
48 glossary entries were reviewed. The original download remains unchanged.

The repository version preserves mathematical corrections already present in the
supplied map and clarifies cover direction, finite-poset diagram scope, and the
Boolean-algebra convention. See [source notes](references.md) and
[coverage and validation](coverage.md) for source errata and limits.
