# Graphs

Standalone Graph Theory learning map with 39 knowledge nodes, 156 practice questions,
and 47 bilingual glossary entries. Open [index.html](index.html), or use the server
instructions in the [root README](../../README.md#run-locally). The topic guide and
navigation connect all available maps through the [topic guide](../../index.html).

Start with Sets and Relations. Functions helps with isomorphisms and colorings;
Matrices helps with adjacency representations; Counting supports enumeration and
coloring counts. The suggested browsing sequence does not require finishing every
earlier map first.

Topics include graph definitions and families, degree sequences, adjacency matrices,
isomorphism, paths and connectivity, Euler and Hamilton routes, vertex coloring,
planarity, and chromatic polynomials. The editable laboratory supports 2–9 vertices,
edge toggling, BFS queries, traversal attempts, and color assignments. The Königsberg
preset retains parallel edges. Edge editing adds one missing non-loop edge or removes
one existing copy; it does not create new parallel edges or loops.

Each four-question check shuffles questions and answer choices. Mastery requires
4/4; 3/4 is partial. Complete a check before feedback is revealed, and use Reset check
to retry. Mixed Practice draws up to 14 questions from explored nodes (or all nodes
when none are explored) without changing individual mastery. Progress stays in this
browser's localStorage when available; there is no account or synchronization.

## Import and review

Imported from `Graphs_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Steven T. Dougherty, Frederique Oggier, and Murong Xu, *Graphs*, supplied in five PDF
parts containing printed pages 1–46. All 39 nodes, 156 answer keys/explanations, and
47 glossary entries were reviewed.

The repository version clarifies formula domains and graph conventions, guards saved
progress, fixes grading and stale state, and corrects graph-laboratory edge cases.
The original download remains unchanged. See [source notes](references.md) and
[coverage and validation](coverage.md) for scope and limitations.
