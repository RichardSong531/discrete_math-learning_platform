## Source qualifications

The supplied chapter contains apparent errors that should not be copied as general rules:

- Page 4, indicator-function prose should refer to membership in S, not A.
- Page 13, Theorem 3(4) should be f(f⁻¹(B₁)) ⊆ B₁, not an arbitrary B₂.
- Page 16, the claim about non-vertical lines needs a nonzero slope for bijectivity ℝ→ℝ.
- Domain restriction alone does not ensure surjectivity onto an unchanged codomain.
  The module explicitly specifies x²:[0,∞)→[0,∞) when using the square-root inverse.

The module is a learning prototype, not a transcription or complete solution set.
