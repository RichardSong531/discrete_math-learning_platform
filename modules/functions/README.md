# Functions

Standalone interactive learning map with 30 knowledge nodes and 120 practice questions.
Open [index.html](index.html), or use the local server in the [root README](../../README.md#run-locally).

Start with Sets and the basic definition of a relation. Coverage includes function validity,
domain/codomain/range, common families, composition, inverses, image/preimage, injective and
surjective functions, finite counting, and proof patterns. Matrix examples are optional enrichment.

Progress is saved in this browser's localStorage. Mixed Practice reviews opened topics (or
all topics if none are opened), without changing node mastery. Submitted sets are locked;
use New set or New mixed set to retry. There is no account or synchronization.

## Import and review

Imported from `Functions_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Jennifer F. Vasquez's supplied Functions chapter. The repository version corrects injectivity
and inverse-domain wording, validates counting inputs, expands the property classifier to
unequal set sizes, and prevents incomplete/repeated quiz submissions from distorting feedback.
The original download is unchanged. See [source notes](references.md) and [coverage](coverage.md).
