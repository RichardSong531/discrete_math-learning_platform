# Functions coverage and review

Reviewed 2026-09-18 against the supplied 19-page Functions chapter. This is a source-aligned
prototype; it is not a verified syllabus or a guarantee of exam coverage.

## Included

The 30 nodes cover definitions and function validity; domain/codomain/range; finite function
counting; common function families; Boolean and matrix examples; restrictions; pointwise
operations; equality; composition; inverse functions and preimages; injection, surjection,
bijection and finite cardinality; injective/surjective proof patterns; and composition theorems.
The 120 question keys and their explanations were read during review. Corrections to wording
and interactions are described in the module README; reported source errors are in references.

## Remaining depth

The practice format is multiple choice. Written proof production is not assessed. The chapter's
full exercise sets are not reproduced. Image/preimage union/intersection laws (Theorem 3), the
restriction-of-an-injection theorem, and more substantial composition-domain exercises need
additional worked practice. Indicator functions currently appear in the cheat sheet rather than
a dedicated lesson. These are coverage limitations, not completed features.

The 80% mastery label is a prototype quiz rule based on four questions per node; it does not
establish durable understanding. Recommendations are module-local.
