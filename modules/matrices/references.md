## Source qualifications

- Page 12, Example 14: an intermediate subtraction should read `1−1`, consistent with
  the displayed final zero matrix.
- Page 14, Example 17: the solution's entry (2,1) should be −4, not 2. The map uses a
  separate correct example and computes `B−A` in its lab.
- Page 22, Example 24: the surrounding text calls the 2×2 and 3×3 permutation matrices
  order 1; their orders are 2 and 3.
- Page 27, Equation (17): the three-ride matrix should contain `H→Z = 1`, since
  `H→Z→M→Z` is a three-ride walk. The map computes Boolean powers from the direct
  connections and obtains the correct entry.
- Page 29, after Theorem 9: determinant scaling is `det(αA)=αⁿdet(A)` for an n×n
  matrix. The exponent 2 applies to 2×2. The map preserves this distinction.
- Page 32, answer 16: a requested 5×5 identity is shown as 4×4. The map's general
  identity-matrix definition is correct.

Boolean matrix powers indicate whether walks exist; they do not count walks. A
permutation matrix is square and has only 0/1 entries with exactly one 1 per row and
column. These conditions are explicit in the reviewed map.
