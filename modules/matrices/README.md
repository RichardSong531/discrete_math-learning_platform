# Matrices

Standalone interactive learning map with 37 knowledge nodes, 148 practice questions,
and 44 glossary entries. Open [index.html](index.html), or use the local server in the
[root README](../../README.md#run-locally). Topic navigation connects all seven maps.

Start with basic arithmetic, Logic, Sets, and Functions. The suggested browsing route
places Matrices after Integers; finishing Integers or Permutations is not required for
every lesson. Permutation matrices connect back to the Permutations map, and Boolean
matrices connect to Logic and Relations.

Coverage includes notation and dimensions; vectors and special matrices; scalar
multiplication, addition and subtraction; row-column products and their laws;
transformations and permutation matrices; Boolean operations and directed-rail
reachability; transpose; and 2×2 determinants. Editable labs show the computations.

Progress is saved in this browser's localStorage when available. Each node has four
questions, with shuffled question and option order; mastery requires 4/4. Mixed Practice
reviews opened nodes (or all nodes when none are opened) without updating node mastery.
Use Reset check or a new mixed set to retry. There is no account or synchronization.

## Import and review

Imported from `Matrices_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Jason M. Graham, *Matrices*. All lesson nodes, answer keys/explanations, and glossary
terms were reviewed. The repository version clarifies several definitions and hardens
lab input, grading, storage recovery, and keyboard interaction. The original download
is unchanged. See [source notes](references.md) and [coverage and validation](coverage.md).
