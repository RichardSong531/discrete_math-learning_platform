# Permutations

Standalone interactive learning map with 25 knowledge nodes and 100 practice questions.
Open [index.html](index.html), or use the local server in the [root README](../../README.md#run-locally).

Start with Functions and bijections. Coverage includes permutation notation, orbits and fixed points,
counting, composition, transpositions, parity, inverses, Japanese ladders, combing, and inversions.

Progress is saved in this browser localStorage. Mixed Practice reviews opened topics (or all topics
if none are opened), without changing node mastery. Submitted sets are locked; use Reset check or
New mixed set to retry. There is no account or synchronization.

## Import and review

Imported from `Permutations_Interactive_Knowledge_Map_Enhanced.html` and reviewed against
Steven T. Dougherty, *Permutations*. The repository version rejects overlapping cycle input,
handles fixed-point orbit diagrams, keeps practice counts and score badges current, and states
the four-question mastery rule directly. The original download is unchanged. See [source notes](references.md)
and [coverage](coverage.md).
