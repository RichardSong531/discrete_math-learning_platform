## Source qualifications

The supplied chapter contains apparent wording and notation errors that should not be copied as general rules:

- Page 3, the orbit-partition proof changes variable names mid-proof.
- Page 7, even and odd permutations are defined using numbers of transpositions, although one sentence says permutations.
- Page 7, Theorem 5 counts even and odd permutations, although its heading says transpositions.
- Page 8, Example 20 calls the single transposition `(1,2)` even; it is odd. The HTML uses the correct rule.
- Page 9, one inverse-cycle example uses periods where commas are intended.

The module is a learning prototype, not a transcription or complete solution set.
