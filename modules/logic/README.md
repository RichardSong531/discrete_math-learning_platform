# Logic

Standalone interactive learning map: 20 knowledge nodes and 96 practice questions.
This is an imported prototype, not an independently reviewed curriculum.

Open [index.html](index.html) in a browser or follow the local server instructions in
[the root README](../../README.md#run-locally). GitHub displays HTML source rather than running it.

The module includes a dependency graph, lessons, interactive practice, mastery checks,
recommended next concepts, mixed practice, and a cheat sheet. Progress is saved in
browser-local `localStorage`; there is no account or cross-device synchronization.
