# Sequences & Recurrences

Standalone learning map with 38 knowledge nodes, 152 practice questions, and 48
bilingual glossary entries. Open [index.html](index.html), or follow the server
instructions in the [root README](../../README.md#run-locally). The shared
[topic guide](../../index.html) connects the available chapters.

Start with Functions and the basic proof methods in Proofs. The main path covers
summation notation, sequences and indexing, arithmetic and geometric rules,
ordinary and strong induction, recurrence definitions and initial values,
first-order linear recurrences, and second-order characteristic roots.
Generating functions provide another solution method. The source explicitly
marks its matrix and diagonalization section as optional; study Matrices before
that extension.

Interactive panels explore finite sums, sequence terms, proof-outline ordering,
counterexamples, recurrence iteration, characteristic roots, generating-function
coefficients, and matrix updates. Comparing a few terms can uncover a mistake or
support a conjecture; it does not prove a formula for every index. The strong
induction activity outlines existence of prime factorizations, not uniqueness.

Each node has a four-question check. A complete 4/4 check marks mastery; 3/4 marks
partial progress. A shuffled retry starts a fresh attempt. Mixed Practice draws
up to 12 questions without changing individual-node mastery. Progress stays in
the current browser when storage is available; there is no account or sync.

## Import and review

Imported from `Discrete_Math_Sequences_Interactive_Knowledge_Map_Enhanced.html`
and reviewed against the supplied 33-page *Chapter 4: Sequences*. The
[source collection](https://sites.google.com/view/discretemathematicsresources/home)
credits Jose Franco and Pedro Morales-Almazan. All 38 nodes, 152 question keys
and explanations, and 48 glossary entries were reviewed. The original downloads
remain unchanged; the PDF is not included in this repository.

The module keeps the source's Fibonacci convention `F_0=F_1=1`, corrects several
source indexing and formula errors, and distinguishes finite numerical evidence
from proof. Its scope is not a claim about an instructor's current syllabus.
See [source notes](references.md) and [coverage and validation](coverage.md).
