# Discrete Probability

Standalone Discrete Probability learning map with 44 knowledge nodes, 176 practice
questions, and 56 bilingual glossary entries. Open [index.html](index.html), or
follow the server instructions in the [root README](../../README.md#run-locally).
The shared [topic guide](../../index.html) connects the available chapters.

Start with Sets, Functions, and Counting. Logic supports conditional statements;
Graphs and Matrices help with the optional graph-walk examples. The recurrence
examples offer a connection to the planned Sequences & Recurrences chapter;
finishing that chapter is not required to begin probability.

The core path covers sample spaces and events, probability axioms, equally likely
and weighted outcomes, counting models, conditional probability, independence,
total probability, Bayes' theorem, discrete random variables, expectation, and
variance. Gambler's ruin, recurrent random walks, graph hitting probabilities,
Poisson distributions, and higher moments provide additional depth. Their
presence does not establish coverage of an instructor's current syllabus.

Interactive panels let learners enumerate dice and coin events, choose sampling
models, inspect conditioning and independence, explore Bayesian updates, edit
finite probability mass functions, transform variables, and compare theoretical
results with simulations. Infinite-support distributions show a finite portion
of the mass and report the omitted tail. A simulation illustrates a model; it
does not prove a theorem or guarantee a particular observed frequency.

Each node has a four-question check. A complete 4/4 check marks mastery; 3/4 marks
partial progress. A shuffled retry starts a fresh attempt. Mixed Practice draws
up to 12 questions without changing individual-node mastery. Progress stays in
the current browser when storage is available; there is no account or sync.

## Import and review

Imported from `Discrete_Probability_Interactive_Knowledge_Map_Enhanced.html` and
reviewed against Joseph Klobusicky's supplied 41-page *Discrete Probability*
chapter. All 44 nodes, 176 question keys and explanations, and 56 glossary entries
were reviewed. The original downloads remain unchanged; the PDF is not included
in this repository.

The repository version preserves the map's corrections to several source errors
and clarifies probability-model assumptions, conditioning on positive-probability
events, geometric waiting-time conventions, and the limits of numerical examples.
See [source notes](references.md) and [coverage and validation](coverage.md).
